前端会怎么用

  • 扫码签到 → 工作人员确认 → 直接打印该人员标签（1 张）
  • 现场注册 → 填完桌号确认 → 直接打印该人员标签（1 张）
  • 签到台人员列表：每人右侧「打印」按钮，点一下出标签
  • 搜索到某个人：可以「仅打印」，不改变签到状态
