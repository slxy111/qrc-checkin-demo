二维码签到与数据查询平台 · 可运行版（演示）
==============================================

【怎么打开】
双击 index.html（用 Chrome 或 Edge）。
  · 第一次打开会看到导航页，按上面「建议按这个顺序试」走一遍就能了解全流程。
  · 后台页面需要登录，共 8 个测试账号（登录页上点一下即可自动填入）：
      管理后台 5 个：admin01 / admin02 / admin03 / admin04 / admin05
      签到台   3 个：kiosk01 / kiosk02 / kiosk03
      密码统一：123456
    右上角头像上的数字（01、02…）就是当前登录账号的编号，方便现场区分是谁在操作。
    管理后台账号：导入、导出、补签、设计打印格式、结束签到；签到台账号：扫码、检索代签、现场注册、打印标签，
    且不能进入后台页面（会被挡回登录页）。
    在「系统设置 → 账号」里可以看到全部 8 个账号并单独修改密码。
  · 参会人自助注册不会生成登录账号——注册只是建档并发二维码，不需要登录。

【能做什么（都是真的能点、能存的）】
1. 名单管理：支持 Excel（.xlsx）和 CSV——把文件拖进虚线框或点按钮选择；也可以直接粘贴内容。
   老版 .xls 请在 Excel 里「另存为」.xlsx 或 .csv。系统自动跳过说明行、识别表头，按「姓名 + 公司／部门」去重合并，
   给出逐行校验报告（号码格式、类别不在字典、桌号为空、重复行），确认后写入。
   导入后，名单里出现的「公司／部门」和「类别」会自动成为这场活动的下拉选项（人员库、签到查询、
   短信范围、现场注册表单都是同一份），不需要手工维护；要额外补充，可在「系统设置 → 字典」里添加。
2. 签到台：输入编码（或直接用扫码枪扫码）即签到；也可按姓名 / 手机号 / 后四位检索代签；
   右上角有「活动」下拉，可以在多场活动之间切换（切换后这场活动的人员、统计、二维码都跟着变）；
   搜索后先显示那个人的那一行，工作人员点这一行的「签到」按钮完成签到；
   列表里每个人右侧都有「签到」和「打印」两个按钮，点哪个都行。三种状态色块提示。
3. 确认后打印：签到成功后点「打印标签」，或现场注册填完桌号点「确认并打印标签」，
   直接打印一张标签（1 份）。
4. 打印模板设计（后台）：每场活动前设计一次——标签尺寸、行间距、二维码、每行字段与字号；
   改完保存立即对前端生效，带实物比例预览和打印测试页。
5. 现场注册：新人扫注册二维码 → 手机填表（姓名/公司/手机号/职务必填）→ 弹「注册成功，
   请与工作人员确认桌号」→ 后台现场注册列表实时刷新并高亮 → 补桌号、备注 → 可保存并打印。
6. 签到查询 / 统计汇总 / 短信通知 / 二维码管理 / 投屏看板 / 操作日志：都能点，数据都是真的。
7. 导出：已签到 + 未签到两张 CSV（Excel 直接打开）、现场注册名单、短信发送文件（手机号/内容/姓名）。

【打印怎么设置纸张】
点「打印标签」会弹出浏览器打印对话框：
  · 目标打印机选标签打印机
  · 纸张选标签规格（默认 70×30mm，可在后台改成 60×40 / 50×30 / 40×25）
  · 边距选「无」，缩放保持 100%（不要选“适应页面”，否则会缩小贴不上）

【二维码怎么扫才能到对应界面】
先记住一句话：二维码里装的是一行网址，手机能打开这行网址，才能扫开。

系统设置里有一项「二维码指向」，两种模式：
  · 演示模式（默认）：二维码指向本站页面。用「启动本地服务器.cmd」打开网站后，
    二维码里是 http://你的电脑IP:8000/mobile-pass.html?c=编码 这样的地址——
    手机连同一个 WiFi，扫了就直接进这个人的个人二维码页；扫注册二维码则进注册表单。
  · 正式模式：二维码指向你在上面配置的域名（形如 https://你的域名/s/编码），
    适合已备案、公网可访问的正式环境。
注意：如果网站是用 file:// 直接双击打开的，二维码里的地址手机扫不开，
  想真机扫码测试就双击「启动本地服务器.cmd」，然后从打印出来的那个网址进入。

【手机扫不开二维码时，按这三条检查】
1. 网址必须是「电脑的局域网地址」，不能是这两种：
   · file:// 打开 → 二维码里是占位域名（打不开）；
   · http://localhost:8000 打开 → 手机上 localhost 指的是手机自己（打不开）。
   现在只要服务器在运行，页面会自动把 localhost 换成这台电脑的局域网 IP，
   服务器窗口里那行「手机打开」就是正确地址，请用它打开本站。
2. 手机必须连「同一个 WiFi」（不能用手机流量、不能在另一个网段）。
3. 电脑上的黑窗口要保持开着（服务器在运行）；第一次运行 Windows 会弹防火墙提示，
   要勾「专用网络」并点允许，否则手机连不上电脑。

自检三步（照顺序试，能定位到问题在哪）：
   ① 电脑上用「手机打开」那行地址能不能打开？
   ② 手机浏览器「手动输入」同一个地址，能不能打开？
   ③ 手机能打开这个地址后，再扫码就一定能进（二维码里就是这个地址）。
   如果 ① 能、② 不能 → 是网络或防火墙的问题，不是二维码的问题：
   · 确认同一个 WiFi；
   · 确认防火墙允许（Windows 安全中心 → 防火墙 → 允许应用通过防火墙）；
   · 有些公司/酒店 WiFi 开了「客户端隔离」，手机和电脑互相访问不了，
     这时改用手机热点：电脑连手机热点，再用热点网段的 IP。

【数据存在哪】
· 用「启动服务器.cmd」打开（推荐）：数据保存在这台电脑的服务器上（文件夹里的
  data.json），手机和电脑共用同一份数据——手机扫码注册，电脑后台几秒内就能看到；
  电脑补桌号，手机个人页也会跟着更新。换台设备、清缓存都不影响。
· 用 file:// 直接双击 index.html 打开：数据只存在当前浏览器里，各设备互相看不到
  （适合你一个人试功能，不适合现场多设备联调）。
正式上线时把这一层换成真正的数据库即可，页面逻辑不用改。

【想清空共享数据】
关掉服务器窗口，删掉文件夹里的 data.json（和 data.version），再重新启动服务器即可；
或在后台「系统设置 → 重置演示数据」里重置。

【可选：用本地服务器打开（想让手机也扫码试）】
双击「启动本地服务器.cmd」，它会在本机开一个 http://localhost:8000 的地址并自动打开浏览器；
同一 WiFi 下的手机可以用 http://你的电脑IP:8000 打开（脚本会打印出这个地址）。
不用时关掉那个黑色窗口即可。
