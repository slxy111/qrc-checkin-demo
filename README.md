# 二维码签到与数据查询平台（演示版）

公司内部会议／晚宴／培训等现场活动使用的扫码签到系统演示版，纯静态页面，可直接部署到 GitHub Pages。

## 演示账号

| 角色 | 账号 | 密码 |
|---|---|---|
| 管理后台（5 个） | `admin01` ~ `admin05` | `123456` |
| 签到台（3 个） | `kiosk01` ~ `kiosk03` | `123456` |

右上角头像上的数字就是当前登录账号的编号。

## 功能一览

- **名单管理**：上传 Excel（.xlsx）或 CSV，自动跳过说明行、识别表头，按「姓名 + 公司／部门」去重合并，给出逐行校验报告
- **签到台**：扫码／检索签到，列表每行有「签到」「打印」按钮，三种状态色块提示
- **现场注册**：新人扫码填写（姓名、公司／部门、手机号、职务必填）→ 提示「注册成功，请与工作人员确认桌号」→ 后台实时出现 → 补录桌号 → 可保存并打印标签
- **打印标签**：格式在后台「打印模板设计」按活动设计（尺寸、字段、字号、二维码），前端确认后打印一张，贴在提前做好的胸卡上
- **二维码**：系统本机生成（真二维码，非图片占位），每人一个 8 位编码，不依赖第三方服务
- **统计／导出**：按类别、公司／部门分组统计；一键导出「已签到／未签到」两张表、现场注册名单、短信发送文件
- **投屏看板**：会场大屏实时展示到场人数与排行

## 说明（重要）

- 页面里的姓名、公司、桌号都是**占位演示数据**，不代表真实名单。
- 部署到 GitHub Pages 时是**纯静态站点**：数据保存在访问者自己的浏览器里（localStorage），
  所以**手机注册的记录不会出现在电脑后台**——这是没有后端时的限制。
  需要多设备共享数据、现场真实使用，请用本地服务器版本（`启动服务器.cmd`）。
- 二维码里指向的就是本站网址，用手机扫码可直接打开对应的注册页／个人二维码页。

## 建议的体验顺序

1. 用 `admin01 / 123456` 登录后台 → 数据总览
2. 名单管理 → 「载入示例内容」→ 确认导入
3. 打印模板设计 → 调整字段与字号 → 保存
4. 打开签到台 → 输入某人的编码或姓名检索 → 签到 → 打印标签
5. 现场注册记录 → 点姓名补录桌号 → 保存并打印标签
6. 签到查询 → 导出「已签到 + 未签到」
